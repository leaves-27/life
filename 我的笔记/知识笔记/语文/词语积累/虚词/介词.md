# 概述
通常用于引导出时间、地点、方式、原因、对象等概念。

# 常见介词
在 - 表示时间或空间上的存在或位置。例如：“我在家里。”
于 - 多用于书面语，表示时间、地点、范围等。例如：“生于北京。”
从 - 表示起点或来源。例如：“我从学校回家。”
自 - 与“从”相似，但更多用于书面语或正式场合。例如：“自古以来。”
到 - 表示终点或到达的地方。例如：“我到车站接你。”
向 - 表示方向或目标。例如：“我向他请教问题。”
往 - 表示动作的方向。例如：“我往东走。”
朝 - 与“向”类似，表示面对或朝向的方向。例如：“他朝我笑了一下。”
对/对于 - 引出对象或话题。例如：“我对这个问题很感兴趣。”
关于 - 引出相关的话题或内容。例如：“这本书是关于历史的。”
按照 - 根据某种标准或规定进行。例如：“我们按照计划行事。”
根据 - 以某事物为依据。例如：“我根据地图找到了这个地方。”
为了 - 表示目的或动机。例如：“他为了学习而努力。”
由于/因为 - 表示原因或理由。例如：“由于天气不好，飞机晚点了。”
随着 - 随着某种情况的变化而变化。例如：“随着科技的发展，人们的生活越来越便利。”
比 - 用于比较两个或多个事物之间的异同。例如：“我比他高。”
跟/同/和 - 表示并列关系或共同进行某个动作。例如：“我和他一起去逛街。”
被 - 用于被动句，表示主语是动作的承受者。例如：“书被他拿走了。”
让 - 有时也用于被动意义，表示允许或使役。例如：“老师让我回答问题。”
给 - 表示给予或接受的动作。例如：“我给你一本书。”
经过 - 通过某个地方或经历某个过程。例如：“我经过书店时买了一本书。”
通过 - 经过某种途径或方法达到目的。例如：“我们通过努力取得了成功。”
除了 - 表示排除某个部分之外的其他部分。例如：“除了小明，大家都来了。”
对于...来说/而言 - 引出某一主体对某事物的看法或态度。例如：“对于我来说，学习很重要。”
鉴于 - 考虑到某种情况或事实。多用于书面语。例如：“鉴于目前的形势，我们需要做出调整。”
至于 - 引出另一个话题或方面。例如：“至于旅游计划，我还没有决定。”
依照 - 按照某种规则或标准去做。与“按照”相近。例如：“我们依照法律办事。”
顺着 - 沿着某个方向或路径前进。例如：“我顺着小路走到了尽头。”
围绕 - 以某事物为中心展开或讨论。例如：“我们的讨论围绕如何提高效率展开。”
基于 - 以某事物为基础或出发点。例如：“他的观点是基于多年的实践经验得出的。

# 概述
地球上的所有生命都仅仅是一架一架生存机器。
生存机器之间的外部形状和内部结构各不相同，但拥有的复制因子的结构却是大致一样的-即拥有的DNA分子构成都是差不多的（都是双螺旋结构、都是由核苷酸构成的链状结构、核苷酸都由四个碱基构成，仅碱基之间的顺序不一样）。

# 原文按照段落总结
  地球上的生命仅仅只是基因的生存机器，其数量众多。
  不同种类的生存机器大的内外形状、结构、生存方式完全不一样，但它们内部的复制因子却极其相似。即DNA分子都属于同一种类型。
  不管现代的复制因子(即DNA)和原始的复制因子是否一样(即一种情况，原始复制因子和现代复制因子都是同一种，即都是目前的DNA；另一种情况，现代的复制因子取代了原始的复制因子)，其对本文想论述的观点都不影响。本文用现代的复制因子来讨论。

  现代的复制因子(即DNA)的形状和结构：形状是由两条呈螺旋形向上盘旋的核苷酸链构成，构成是由四种碱基按照一定的顺序排列而成的核苷酸链接再彼此链接而成。各生存机器之间的构成碱基一样，但顺序不一样(即使同一物种不同个体间的顺序也不一样)。
  现代的复制因子(即DNA)的存在位置和形态：DNA存在身体内的每一个细胞之中的染色质或染色体中(DNA缠绕蛋白子构成部分。在细胞分裂期叫染色体，在细胞间期叫染色质)，由很多个基因(即多个核苷酸按照特定顺序链接而成的部分)首尾相接构成，要判断哪部分是首哪部分是尾极其困难的。
  现代的复制因子：主要功能是进行复制和制造蛋白质(蛋白质又分为作为组织结构支撑的蛋白质和调节化学过程的蛋白质)。复制时按照等倍数分裂进行分裂。
  基因和以前的复制因子一样，各凭本事进行竞争，同以前一样没有明确目的和事先筹划，但凭借的本事却不像以前那样了。

  现代的复制因子的生活方式：现代的复制因子具有高度的群居性。许多基因一起联合控制人体的某一形状。其可以通过有性生殖进行重新组合。细胞进行减数分裂形成只有23条染色体的性细胞。两个性细胞中的染色体中的基因进行重新组合，组合成新的染色体并进一步组成常规细胞。然后常规细胞进行有丝分裂形成一个个新细胞。

# 概述
地球上的所有生命都仅仅是一架一架生存机器。
生存机器之间的外部形状和内部结构各不相同，但拥有的复制因子的结构却是大致一样的-即拥有的DNA分子构成都是差不多的（都是双螺旋结构、都是由核苷酸构成的链状结构、核苷酸都由四个碱基构成，仅碱基之间的顺序不一样）。

# 原文按照段落总结
  地球上的生命仅仅只是基因的生存机器，其数量众多。
  不同种类的生存机器内外形状、结构、生存方式不一样，但它们内部的复制因子却极其相似。即DNA分子极其相似。
  DNA可能和原始复制因子一样，可能完全不同。如果不同的话，则可以说DNA将原始复制因子取代了。
  DNA的形状和结构：由两条螺旋形的核苷酸链交织而成。各生存机器之间的DNA构成单位碱基是一样的，只是碱基排列的顺序不一样。
  其存在身体内的每一个细胞之中的染色体中。由很多个基因首尾相接构成。
  其主要功能是进行复制和制造蛋白质。

  许多基因一起联合控制人体的某一形状。其可以通过有性生殖进行重新组合。细胞进行减数分裂形成只有23条染色体的性细胞。两个性细胞中的染色体中的基因进行重新组合，组合成新的染色体并进一步组成常规细胞。然后常规细胞进行有丝分裂形成一个个新细胞。

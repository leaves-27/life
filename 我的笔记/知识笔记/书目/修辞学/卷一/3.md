# 概述
  由于演说根据听者的不同可以分为三种不同类型。这三种不同的类型根据讨论的事情涉及的时间维度、目的、要采取的行为不同又包含三种不同的题材。所以，要掌握好演说，需要掌握这三种题材构成的命题。具体命题有可能的事情或不可能的事情构成的命题、已经发生的或没有发生的事情构成的命题、将要发生或不会发生的事情构成的命题、光荣的或可耻的(不正当)命题、正当与不正当(不当、不妥、非法、无理、邪恶)、有益的或无益的、大小构成的命题。

## 演说的三种类型
  政治演说
  诉讼演说
  典礼演说

### 政治演说
  时间：将来
  目的：有益或无益(有害)  
  要采取的行动：劝说或劝阻

## 诉讼演说
  时间：过去
  目的：正当/正义或无理(不正当)/不义
  要采取的行动：控诉或辩护

## 典礼演说
  时间：当下
  目的：光荣或可耻
  要采取的行动：表扬、谴责

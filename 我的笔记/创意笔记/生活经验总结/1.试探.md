# 试探人的人的总体策略
  先扔个小石头，看你什么反应。你退了，他就往前走一步。你炸了，他就装无辜。 

# 试探人的常见行为:
  1.玩笑式贬低：你怎么这么较真啊？
  2.当众让你难堪：你怎么连这个都不知道？咱就事论事吧。
  3.模糊责任：这块你先弄一下呗，回头再说。先确认一下分工/项目边界吧
  4.假客气，真推活：你能力强，帮帮我嘛。

  5.小越界：用一下你东西怎么了？

# 他的后续反应
  1.你急---------他继续逗你
  2.你解释-------他会觉得你心虚了
  3.你笑了-------他会觉得你同意了
  4.你沉默了-----他会觉得你默许了

# 应对策略
  核心：不再顺着他\不再给他便利\不再帮他\把事转到明面

  第一次就让他碰壁；

# 试探升级
  1.一句话挡回去；
  2.公开确认，留痕 
  3.向上同步或直接冷处理
  4.找领导/HR，不再私下纠缠 

# 万能话术
  1.这个我不接；
  2.你刚才那句话我不接受
  3.工作的事，群里说
  4.确认了再做。负责人是谁？中途出了问题找谁？
  5.用之前问我
  6.等我说完
  7.不好笑，说正事

# 相处准则
1.信任分层：私人信任别轻易给同事；工作信任先给小事，再给大事；
2.不要把软肋轻易示人：家庭状况、经济状况、情绪弱点、对领导的不满别随便说;
3.重要事留痕：分工、进度、决策、交接
